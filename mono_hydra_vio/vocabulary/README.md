# Kimera Loop-Closure Vocabulary

The expanded `ORBvoc.yml` file is larger than GitHub's normal file limit and is
therefore not tracked in the public repository.

For local runs, restore it from the tracked archive:

```bash
cd src/mono_hydra_vio/vocabulary
unzip ORBvoc.zip
```

The ITC/uHumans/7Scenes launch files expect:

```text
src/mono_hydra_vio/vocabulary/ORBvoc.yml
```
